# rustdesk-server-nightly

Nightly Docker image for the RustDesk Server OSS

## Usage

Replace the image name from `rustdesk/rustdesk-server` to `ghcr.io/nerahikada/rustdesk-server-nightly`

Example:

```bash
docker pull ghcr.io/nerahikada/rustdesk-server-nightly
docker run -it --rm ghcr.io/nerahikada/rustdesk-server-nightly hbbr
docker run -it --rm ghcr.io/nerahikada/rustdesk-server-nightly hbbs
```
